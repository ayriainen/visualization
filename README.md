# Interactive data visualization project

This is a University of Helsinki course project about interactive data visualization. It uses Plotly.js to build interactive choropleth maps and line charts of global health and development data, sourced from [Our World in Data](https://ourworldindata.org/). It uses the datasets for life expectancy at different ages, infant mortality, child mortality, fertility rate, median age, urban population share, GDP per capita (PPP), literacy rate and Gender Inequality Index.
